## 项目概述 (1 分钟读懂)

QuantInsight Pro 是慧点资本联合杭州永字资管打造的**新一代资管科技平台**, 通过 AI 投研智能体 + 5 类另类数据 + 9 类客户分群, 为 1.5 万+ 机构投资者提供服务.

**5 个核心数字** (2030 目标):
- 客户: **620 家**
- 营收: **7.95 亿**
- 净利润: **1.98 亿** (净利率 25%)
- 估值: **40 亿** (5x P/S)
- IRR: **28%** (5 年累计融资 4.35 亿)
