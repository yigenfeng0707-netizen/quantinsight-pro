## 🎯 项目概述（1 分钟读懂）

**QuantInsight Pro** 是**业内首家把 SHAP 可解释性深度集成到 A 股多因子选股的 AI 平台**，已与永字资管签署战略合作并完成 5 只产品 POC 验证。

我们为 **4 类客户群**（头部私募 / 中小私募 / 券商投顾 / 家族办公室）提供 **3 模态融合**（量价 + 宏观 + 另类数据）的另类数据量化投研能力，解决传统 AI "只给答案不给理由" 的痛点。

## 🌟 核心创新：SHAP 可解释 AI

```
传统 AI 选股：
  AI: "推荐茅台" → ❓ 为什么？AI 不告诉你

QuantInsight Pro：
  AI: "推荐茅台" → ✅ ROE 贡献 +0.32 / 营收增速 +0.18 / 20 日动量 +0.15
              → ✅ 17 因子 SHAP 贡献度全部可视化
              → ✅ 监管合规 + 客户信任 + 分析师省心
```

**4 层技术叠加**：
- **数据层**：11.4 年 × 500 只股票 × 17 因子 = **97,000+ 数据点**
- **算法层**：XGBoost 多因子训练 + SHAP TreeExplainer
- **AI 层**：Qwen3.7-Max 微调 + RAG 真实数据接地
- **应用层**：A 股本土化因子 + 监管合规备案

## 🚀 快速开始

### 在线体验
访问 **https://3blue1brownlab.cn**（HTTPS + Let's Encrypt SSL）

### 本地运行
```bash
git clone https://github.com/yigenfeng0707-netizen/quantinsight-pro-afac2026.git
cd quantinsight-pro-afac2026
pip install -r streamlit_app/requirements.txt
cd streamlit_app
streamlit run app.py
```

### 渲染 Demo 视频
```bash
# 3 分钟 Demo V2
cd demo-video-remotion
npm install && npm run render:v2

# 5 分钟决赛路演 V1
cd demo-video-remotion-pitch
npm install && npm run render
```
