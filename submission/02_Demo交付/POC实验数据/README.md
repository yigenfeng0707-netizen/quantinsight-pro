## 二、指标定义

| 指标 | 英文 | 计算方式 |
|------|------|----------|
| **年化收益** | Annual Return | `(1 + total_return)^(252/trading_days) - 1` |
| **夏普比率** | Sharpe Ratio | `(年化收益 - 无风险利率) / 年化波动率`，无风险利率取 3% |
| **最大回撤** | Max Drawdown | 净值峰值到谷底的最大跌幅 |
| **卡玛比率** | Calmar Ratio | `年化收益 / |最大回撤|` |
| **胜率** | Win Rate | 盈利交易日占比 |
| **交易次数** | Trades | 仓位变化次数（T35 精确计数） |

## 三、策略说明

| 策略 ID | 中文名 | 逻辑简述 |
|---------|--------|----------|
| `buy_hold` | 买入持有 | 基准策略，首日买入持有至末日 |
| `ma_cross` | 双均线 | 短期均线上穿长期均线买入，下穿卖出 |
| `mean_reversion` | 均值回归 | 价格偏离均值时反向交易 |
| `multi_factor` | **多因子（核心）** | 动量 + 反转 + 排名合成信号 |
| `momentum` | 动量 | 趋势跟随，近期涨幅排名靠前买入 |

## 五、T35 修正说明（重要）

早期 T30 版本多因子年化报告 **19.22%**，经 T35 开源引擎修正为 **8.56%**。

**差异原因**：
- T30 旧版 `trades = int(turnover.sum() / 2)` 浮点截断导致交易计数和收益计算偏差
- T35 新版 `trades = (position.diff().abs() > 0).sum()` 精确计数
- **T35 版本更准确，提交数据以 T35 为准**
