## 四、制作方式（三选一）

### 方式 A：自动化录制（推荐）

使用 Cursor `demo-video-factory` 技能：

```powershell
# 1. 启动 Demo
cd streamlit_app
streamlit run app.py

# 2. 创建 storyboard 后运行
powershell -File ~/.cursor/skills/demo-video-factory/scripts/run_demo_video.ps1 `
  -Storyboard demo.storyboard.json

# 3. 复制输出
Copy-Item demo-output/demo_3min.mp4 `
  submission/02_Demo交付/QuantInsight_Pro_Demo_3min.mp4
```

**前置条件**：Node.js + Playwright + ffmpeg + edge-tts

### 方式 B：OBS 手动录屏

1. 分辨率设为 1920×1080
2. 按本文分镜顺序操作 Demo
3. 后期用剪映/Premiere 配音（可用 edge-tts 生成旁白 MP3）
4. 导出 H.264 MP4

### 方式 C：使用现有 SRT 字幕素材

仓库内已有字幕文件（无配套 MP4）：

| 文件 | 内容 |
|------|------|
| `QuantInsight_Pro_Demo_Video_V1.srt` | 3 分钟总览字幕 |
| `QuantInsight_Pro_Tech_Video_v1_ai_qa.srt` | AI 问答专题 |
