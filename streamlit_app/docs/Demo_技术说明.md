## 二、核心模块

### 2.1 首页 (`🏠 首页`)
- **功能**：展示平台定位 + 三大模块入口 + 实时指数
- **数据**：HS300/ZZ500/CYB 最新收盘价 + 涨跌幅
- **性能**：数据缓存 1 小时

### 2.2 AI 投研问答 (`🤖 AI 投研问答`)
- **当前实现**：基于关键词匹配的 mock 回答
- **预设场景**：新能源、半导体、消费
- **未来升级**：接入 DeepSeek/Qwen API
- **响应时间**：< 1.5 秒

### 2.3 另类数据仪表盘 (`📡 另类数据仪表盘`)
- **3 个子模块**：
  - 卫星图像：模拟工业园区开工率（基于真实行业规律）
  - 舆情分析：模拟 8 个行业情感数据
  - 供应链追踪：产业链 4 环节景气度
- **未来升级**：接入真实 Sentinel-2 / Google Trends / 海关数据

### 2.4 量化策略回测 (`📈 量化策略回测`)
- **3 类策略**：
  - 双均线动量 (MA20/MA60)
  - 布林带均值回归 (20, 2σ)
  - 多因子合成（动量+反转）
- **核心指标**：年化收益、夏普、最大回撤、胜率、Calmar、信息比率
- **数据源**：akshare 公开 A 股日线
- **回测期间**：2020-01 ~ 2026-06（5.4 年）

### 2.5 行业分析 (`📊 行业分析`)
- **数据源**：akshare 行业成分股（sw_index_third_info + stock_board_industry_cons_em）
- **支持行业**：半导体、新能源车、医药、白酒、银行、证券、地产、军工
- **展示内容**：成分股涨跌幅 TOP 20 + 完整数据表

## 三、数据流详解

### 3.1 akshare 数据获取
```python
import akshare as ak

# 沪深300
df = ak.stock_zh_index_daily(symbol='sh000300')
# 返回字段：date, open, high, low, close, volume

# 行业成分股
df = ak.stock_board_industry_cons_em(symbol='BK0438')
# 返回字段：代码, 名称, 最新价, 涨跌幅, ...
```

### 3.2 Streamlit 缓存机制
```python
@st.cache_data(ttl=3600)  # 缓存 1 小时
def load_hs300():
    df = ak.stock_zh_index_daily(symbol='sh000300')
    return df
```

**优势**：
- 减少重复 API 请求
- 加快页面加载（缓存命中时 < 100ms）
- 降低 akshare 接口压力

### 3.3 策略计算流程
```
原始数据 → 计算指标（MA/STD/Rank） → 生成信号 → 计算日收益
   ↓                                           ↓
   └──────────── 扣除交易成本 ────────────────┘
                                                ↓
                                          累计 NAV
                                                ↓
                                  计算夏普/回撤/胜率
```
